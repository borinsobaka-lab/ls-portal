# Помощник входа FitBase

Для «Аналитики» портала → «Интеграция FitBase» → «Основания записей» (сборщик
оснований записей со страниц FitBase — их `automatic-basis`, ANALYTICS.md,
«FitBase, часть 5»).

Вход в FitBase защищён CAPTCHA, поэтому входит владелец сам — в отдельном окне
браузера на своём компьютере. Помощник после входа берёт cookies FitBase этого
окна и передаёт их порталу с одноразовым кодом. Пароль остаётся в FitBase,
cookies на экран не выводятся; портал хранит их зашифрованными и сам обновляет,
когда FitBase их продлевает. Отозвал FitBase сессию — портал покажет «Нужен
повторный вход», помощника запускают ещё раз.

## Windows

1. Один раз установить Python 3 с https://www.python.org/downloads/ (отметить
   «Add python.exe to PATH»).
2. Скачать эту папку (на GitHub: «Code» → «Download ZIP», папка
   `deploy/fitbase-session`), распаковать.
3. На портале: «Интеграция FitBase» → «Основания записей» → «Подключить через
   помощника» → «Скопировать код».
4. Запустить «Подключить FitBase.bat». Первый запуск ставит пакет `playwright`
   (минута-две). Помощник спросит код — вставить (правая кнопка мыши) и нажать
   Enter.
5. В открывшемся окне Chrome (или Edge) войти в FitBase, пройти CAPTCHA,
   оставить «Запомнить меня». Когда откроется FitBase, вернуться в чёрное окно и
   нажать Enter.
6. «Готово: портал проверил доступ ко всем клубам студий» — окно можно
   закрыть. Дальше включить задачу на странице «Основания записей».

Код действует 15 минут и один раз — для повторного входа получить новый.

## macOS / Linux

```bash
python3 -m venv .env && .env/bin/pip install playwright
.env/bin/python fitbase_session.py
```

## Без кода (вставить вручную)

`fitbase_session.py --save session.json --origin https://<сеть>.fitbase.io` —
сохранить сессию в файл; его содержимое вставить на портале («Вставить сессию
вручную») и файл удалить.

Проверки без браузера: `python -m unittest test_fitbase_session.py`.
