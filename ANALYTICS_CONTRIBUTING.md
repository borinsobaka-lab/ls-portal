# Как вести «Аналитику» на портале

Инструкция для разработчика раздела «Аналитика» (перенос портала аналитики
Lady Stretch — ANALYTICS_PLAN.md, что уже сделано — ANALYTICS.md). Вы будете менять раздел
через Claude Code, ИИ-программиста в браузере. Программировать самому не
нужно: вы описываете задачу словами, Claude пишет код. Ваши правки попадают на
портал только после проверки на стороне владельца.

**Что нужно:** компьютер с браузером, почта, платная подписка Claude (Pro или
Max), без неё Claude Code не работает.

## Один раз: подготовка

**1. Аккаунт на GitHub.** GitHub — это сайт, где хранится код портала.

- Откройте https://github.com → **Sign up**.
- Введите почту, придумайте пароль и имя пользователя (логин), подтвердите
  почту кодом из письма.
- Пришлите логин владельцу портала.

Если владелец дал вам доступ к самому репозиторию `borinsobaka-lab/ls-portal`,
форк не нужен: пропустите шаги 2 и 4, в шаге 3 выберите
`borinsobaka-lab/ls-portal`, первое сообщение — _«Я разработчик аналитики.
Задача: …»_, Pull Request в шаге 6 — из ветки `claude/…` того же
репозитория. Правила те же: правку принимает владелец.

**2. Своя копия портала (форк).** Вы работаете в своей копии, основной код
портала она не трогает.

- Войдите в GitHub и откройте https://github.com/borinsobaka-lab/ls-portal
- Справа вверху нажмите **Fork** → **Create fork**.
- Появится ваша копия: `https://github.com/ВАШ_ЛОГИН/ls-portal`. Сохраните
  эту ссылку.

**3. Подключить Claude Code к копии.**

- Откройте https://claude.ai/code и войдите в Claude.
- Claude попросит подключить GitHub: нажмите **Connect GitHub** и войдите в
  GitHub.
- GitHub предложит установить приложение Claude. Выберите **Only select
  repositories** → `ВАШ_ЛОГИН/ls-portal` → **Install**.

## Каждая задача

**4. Обновить копию.** Владелец тоже меняет портал, и копия должна быть
свежей.

- Откройте свою копию `https://github.com/ВАШ_ЛОГИН/ls-portal`.
- Над списком файлов нажмите **Sync fork** → **Update branch**. Если там
  написано «This branch is up to date», ничего делать не нужно.

**5. Дать задачу Claude.**

- На https://claude.ai/code начните новый сеанс и выберите репозиторий
  `ВАШ_ЛОГИН/ls-portal`.
- Первое сообщение начните так: _«Я разработчик аналитики, работаю в форке.
  Задача: …»_. Дальше опишите, что нужно, как объяснили бы человеку: какой
  отчёт, какие цифры, как считать, как должно выглядеть.
- Claude сам прочитает правила проекта, сделает правку, проверит её и
  сохранит в вашей копии.
- В конце попросите: _«Расскажи, что изменилось и что проверено. Напиши текст
  для описания Pull Request»_.
- Одна задача — один сеанс. Для следующей задачи начинайте новый сеанс, перед
  этим снова шаг 4.

**6. Отправить правку владельцу (Pull Request).**

- Откройте свою копию на GitHub. Сверху появится жёлтая полоса с веткой
  `claude/…` → нажмите **Compare & pull request**. Если полосы нет:
  **Contribute** → **Open pull request**.
- Проверьте строку вверху. Слева должно быть
  `base repository: borinsobaka-lab/ls-portal`, `base: main`, справа —
  `head repository: ВАШ_ЛОГИН/ls-portal`, `compare: claude/…`.
- Заголовок — коротко, что сделано. В описание вставьте текст, который
  написал Claude.
- Нажмите **Create pull request** и пришлите ссылку владельцу.

## Что дальше

- Владелец запускает автоматические проверки. Их видно внизу страницы Pull
  Request.
- Если **«Аналитика — пути»** красная, правка задела файлы за пределами
  раздела. Вернитесь в тот же сеанс Claude и напишите: _«Проверка путей
  красная, исправь»_.
- Если красная **«Аналитика — проверки»**, в коде ошибка. Скопируйте Claude
  текст ошибки (нажмите **Details**) и попросите исправить.
- Исправления Claude попадают в тот же Pull Request сами, новый открывать не
  нужно.
- Когда владелец примет Pull Request, правка через несколько минут появится на
  портале.

## Правила

- Меняется только раздел «Аналитика». Claude это знает и сам не полезет в
  другие разделы (правила для него — `CLAUDE.md`, «Разработчик аналитики»).
- Если для задачи нужно что-то за пределами раздела (новый пункт меню, права
  доступа, новая библиотека), Claude напишет это в описании Pull Request, и
  владелец сделает это сам.
- Не пишите Claude настоящие данные клиентов, пароли и ключи. Код портала
  открыт всем.
