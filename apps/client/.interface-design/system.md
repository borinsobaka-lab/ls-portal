# Base40 — клиентское приложение: дизайн-система

Мобильное фитнес-приложение: энергичное, контрастное, «спортзал, мел и жёлтый
неон». Хром приложения кричит капсом, контент говорит спокойно.

## Цвет

- **Бренд**: `--primary` = фирменный жёлтый #FFE500 → `oklch(0.915 0.191 101)`,
  `--primary-foreground` = чернильный #1B1C1F → `oklch(0.227 0.006 271)`.
  Одинаковы в light и dark. **Литералы #FFE500 / #1B1C1F в коде запрещены** —
  только bg-primary / text-primary / border-primary / accent-primary.
- Приглушённый текст — `text-muted-foreground` (бывший литерал #66676D).
- В тёмных зонах (шапки страниц) подписи — `text-white/70`, это осознанный
  локальный паттерн тёмного хрома.
- Инвертированный чип (активный фильтр): `bg-foreground text-background`.
- Тёмный хром оболочки (page-shell) — `#2A2B2F` (единственный допустимый
  литерал поверхности, живёт только в page-shell.tsx).
- Бренд-марки платёжных систем (Mastercard и т.п.) рисуются своими
  фирменными цветами — их НЕ токенизируем.
- Деструктивные действия — `variant="destructive"` у Button, не самодельный
  красный.
- 60/30/10: почти весь экран — нейтральные поверхности, жёлтый только для
  действий и акцентов (CTA, прогресс, активные состояния).

## Типографика

**Шрифт — Roboto** (корпоративный, общий с админкой). Самохостится из
`@fontsource/roboto`, подключён в `styles.css`: веса 400/500/600/700/900.
Google Fonts не дёргаем — работает офлайн, без запросов на сторонние домены,
готово к PWA.

История: раньше стек начинался с «Google Sans»/«Product Sans», а в `__root.tsx`
висели preconnect и stylesheet на fonts.googleapis.com. Google Sans публично
там не раздаётся, поэтому запросы уходили впустую, а приложение рендерилось
системным шрифтом (San Francisco на iPhone) — фирменного шрифта пользователи
фактически не видели. Ссылки убраны.

| Ярус                  | Классы                                                                  | Где                          |
| --------------------- | ----------------------------------------------------------------------- | ---------------------------- |
| Заголовок страницы    | `text-3xl font-black uppercase`                                         | h1 всех страниц              |
| Заголовок секции/шага | `text-2xl font-black uppercase`                                         | h2 главной, шаги онбординга  |
| Контентный заголовок  | `text-2xl font-bold leading-tight` (без caps)                           | название новости, абонемента |
| Body                  | `text-sm` / `text-base`; в drawer'ах — `text-[15px]`                    | основной текст               |
| Caption               | `text-xs`, плотные подписи `text-[11px]`                                | метаданные                   |
| Секц. подпись формы   | `text-xs font-bold tracking-wider text-muted-foreground` + текст капсом | «БАНКОВСКАЯ КАРТА»           |

Правило: хром приложения — `font-black uppercase`; контент — `font-bold` без
caps. Размеры вне шкалы (10/13/15px) не заводить; 15px — только drawer body.

## Контролы

- **Кнопки**: только `<Button>` (`ui/button`). default = жёлтая пилюля
  `h-12 rounded-full bg-primary text-primary-foreground`. Соседние с полями
  кнопки не занижать по высоте — h-12 у всех.
- **Поля**: формы — `<FloatingInput>` (h-14, плавающий лейбл); простые поля —
  `<Input>` (h-12, `rounded-md`, focus-кольцо `ring-ring`). Самодельные
  `<input>` со строкой классов запрещены. Исключение — OTP-ячейки в auth
  (спец-контрол: 6 штук, h-14 w-11 rounded-xl, gap-2, focus ring-primary —
  размер подобран так, чтобы шесть ячеек помещались в строку на 360px).
- Чекбоксы браузерные в оферте — `accent-primary`.
- Кастомные кнопки-плитки (табы расписания, чипы онбординга, bottom-nav) —
  осознанные спец-контролы, но цвета в них только токенами.

## Радиусы

`--radius: 0.625rem`. Кнопки — `rounded-full` (пилюли); поля — `rounded-md`;
карточки — `rounded-2xl`; крупные баннеры/drawer — `rounded-2xl/3xl`; чипы —
`rounded-full`. Не смешивать в одном ряду.

## Глубина

Стратегия — **границы + тональные сдвиги**, без крупных теней:
`border-border` + `bg-card`/`bg-muted`. Инпуты на тон темнее поверхности не
делаем — поля светлые с бордером (утверждённый вид форм).

## Пространство

База 4px. Экранные поля: `px-4` по краям страницы; секции разделяются
`mt-6/mb-3`; внутри карточек `p-4`. Плотность мобильная, воздух между
секциями, а не внутри строк.
